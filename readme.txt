Accessible Website - Connor Singer

Accessibility Features

* Pressing tab allows user to change current selection such as their tab or the content on the screen (navbar use)

* the arrow keys allow the user to scroll up and down to look at the whole page if the page is longer than the screen

* the navBar changes color and size when hovering over it or focusing using the keyboard

* images are aligned in the middle of the screen in order to have the max amount of size the user can look at

* the text also flows completly from one side to the next in order to ensure big paragraphs don't lead to unreadability

* all the images have alt text in order for screen readers to understand

* text sizes are appropriate and the titles are bolded to distinguish between them

* all styling such as size or color or any details are all managed inside of the style.css style in order to maintain consistant styling between pages

* removed the frames from the given files because that does not promote Accessibility

* Allowed for people to realize the navbar titles are actually pages by having page next to each one (redundant but allows for everyone to know its a page and adds a consistant style for the navbar)

* formated the codee in a more readable manner in which allows for an easier time editing the program

* made comments for each part of the project and what it does to the screen

* kept the orginal files to see that major changes between the accessible version and the inaccessible version

* created a readme file in which documents all the major changes for this newly designed website
